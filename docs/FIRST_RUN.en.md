# First run

RCM needs your complete Redemption copy: executable, resources, script library and original chronicles. Select Vampire.exe; the installation is checked before catalogues are prepared. Whole drives are not scanned.

Preferences belong to the application. Chronicles, custom resources, saved versions and playtest results live in the project folder shown in Settings. Its initial location is Documents/Redemption Chronicle Maker. Replacing the program preserves your work.

First run reports actual reading and indexing progress. Later starts reuse catalogues. Cancelling selection does not complete setup. Settings can change language or project folder; restart to apply these changes.

Original game files remain intact. Only our folders under RCM are prepared. Earlier test folders are not automatically migrated or cleaned.
