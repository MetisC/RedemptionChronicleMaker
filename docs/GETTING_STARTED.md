# Primeros pasos

Abre **RedemptionChronicleMaker.exe**. Selecciona **Vampire.exe** si RCM no encuentra tu juego. La preparación inicial lee tu instalación y deja tus proyectos en Documentos, fuera del programa.

En la bienvenida elige **Tutorial rápido**, **Showcase completo** o **Nueva crónica**. En el tutorial, selecciona Anezka en Historia y modifica una frase. Guarda y pulsa **PROBAR EN REDEMPTION (F5)**. RCM valida, construye sólo si hace falta, prepara la crónica y abre el juego.

Dentro de Redemption entra en **Multiplayer → LAN → New Game** y elige el nombre de tu crónica. RCM no controla esos menús. Tras cambiar la estructura, empieza una partida nueva. Para actualizar la prueba, cierra el juego; el editor nunca lo cierra por ti.

Para crear una aventura: escribe el nombre, elige el escenario, coloca una entrada en el suelo con **Campaña → + Entrada**, añade un NPC y usa **Asistente… → NPC que habla**. Los elementos se pueden editar y mover después. Una escena es el contenido; el escenario aporta su geometría original.
