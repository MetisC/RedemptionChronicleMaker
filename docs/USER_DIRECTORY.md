# Carpetas de tus proyectos

El programa y tus proyectos viven separados. La ubicación inicial de trabajo está en Documentos/Redemption Chronicle Maker; se puede cambiar desde Configuración. Contiene chronicles, cache, build, backups y launchers. Las preferencias de aplicación se guardan en la ubicación estándar de datos locales de Windows.

Los ejemplos incluidos son masters: se trabaja sobre una copia. Crear copia limpia conserva tu copia anterior. Duplicar crónica incluye sus recursos propios; no clona caches ni builds.

Las pruebas del juego usan una carpeta por crónica bajo RCM. La instalación original no se modifica. Los accesos opcionales se crean localmente en launchers y no vienen del PC del desarrollador.
