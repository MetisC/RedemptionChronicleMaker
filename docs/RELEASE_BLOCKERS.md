# Bloqueos de publicación final

La versión actual es 1.0.0-rc3. Antes de llamarla 1.0 final, el usuario debe aceptar el primer arranque, la prueba desde F5 y el Showcase, incluyendo guardado/carga y reentrada. Los registros y tests offline no sustituyen esa aceptación visual. El portable también debe probarse en una máquina/VM independiente; no se afirma esa prueba cuando sólo se usa otro directorio de este PC.
