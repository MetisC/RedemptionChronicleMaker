# Primer arranque

RCM necesita tu copia completa de Redemption: ejecutable, recursos, biblioteca de scripts y crónicas originales. Selecciona Vampire.exe; se comprueba la instalación antes de preparar los catálogos. No se busca por todo el disco.

Las preferencias pertenecen a la aplicación. Tus crónicas, recursos propios, versiones guardadas y resultados de prueba quedan en la carpeta de proyectos indicada en Configuración. La ubicación inicial es Documentos/Redemption Chronicle Maker. Puedes reemplazar el programa sin borrar tu trabajo.

El primer arranque muestra progreso real de lectura e indexación. Los siguientes reutilizan los catálogos. Si cancelas la selección, no se marca la preparación como completa. Configuración permite cambiar idioma o carpeta de proyectos; esos cambios requieren reiniciar.

La instalación original se conserva. Sólo se preparan nuestras carpetas dentro de RCM. Una carpeta anterior de pruebas no se migra ni se limpia automáticamente.
