# Getting started

Open **RedemptionChronicleMaker.exe**. Select **Vampire.exe** if RCM cannot find your game. Initial preparation reads your installation and stores projects in Documents, outside the program.

Choose **Quick tutorial**, **Full showcase** or **New chronicle**. In the tutorial select Anezka in Story and edit a line. Save and press **PLAYTEST IN REDEMPTION (F5)**. RCM validates, builds only when needed, prepares your chronicle and opens the game.

In Redemption choose **Multiplayer → LAN → New Game** and select your chronicle by name. RCM does not control these menus. Start a new game after structural changes. Close the game before updating a playtest; the editor never closes it for you.

To create an adventure, enter its name, select a scenario, place an entry on the ground using **Campaign → + Entry**, add an NPC and choose **Assistant… → Talking NPC**. You can edit and move the resulting entities. Scenes contain your authored content; scenarios supply original geometry.
