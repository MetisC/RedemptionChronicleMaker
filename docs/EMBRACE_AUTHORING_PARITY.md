# Strict Embrace authoring parity — rc7

This matrix supersedes the permissive closure claim. Preservation, custom Java,
raw YAML and a similar-looking result do not establish ordinary authoring parity.
COVERED DIFFERENTLY means a normal UI route expresses the same material intent
without writing code/binary files. NATIVE TEST REQUIRED means implemented author
controls with offline evidence, still awaiting observation in Redemption.

**No strict 100% claim:** EAX editing, general native region context, native
sound/light boxes, stationary timed NCP keys and arbitrary code-bearing mod
imports remain unresolved or limited. Geometry-only exclusions do not hide them.
The accepted tutorial and mini chronicle have not been rewritten.
