# Storyteller's Workshop

Open **Full showcase** from Welcome or Help. The circuit uses three scenes and two scenarios. Allow about 15–25 minutes when exploring the optional laboratory.

1. Anezka waits near arrival. Accept the book errand.
2. The guide is nearby. Explore camera presets one at a time, actual animations supported by her model, and path/audio controls. Each experiment allows exiting; combat is optional and uses one basic rat.
3. Travel to the archive. The archivist offers two ways to obtain the book and key. The keeper offers an optional film with movement and sound, or lets you continue directly.
4. Return to the witness. This scene reuses the starting street's geometry with different content. Deliver the book and check the journal. Return to the start to test reentry and persistent state.

The street contains a notice object, a lectern that opens a conversation and an optional laboratory book. These are not native doors. The guide's starting inventory contains a key.

The project guide links to editable entities. Advanced functions, including original doors and travelling tied to an original camera resource, are catalogued with their limits; they are not represented as natively verified by this new Showcase.
