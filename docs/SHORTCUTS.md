# Atajos

| Acción | Atajo |
|---|---|
| Nueva / Abrir / Guardar | Ctrl+N / Ctrl+O / Ctrl+S |
| Deshacer / Rehacer | Ctrl+Z / Ctrl+Y o Ctrl+Shift+Z |
| Duplicar selección | Ctrl+D |
| Filtrar el árbol de la escena activa | Ctrl+F |
| Buscar en la crónica | Ctrl+Shift+F |
| Construir | Ctrl+B |
| Probar en Redemption | F5 |
| Ayuda de atajos | F1 |
| Enfocar selección | F |
| Mover / Girar / Tamaño | 1 / 2 / 3 |
| Eliminar selección | Supr |

En el visor: derecho + WASD/QE navega; izquierdo arrastrado avanza y gira; izquierdo+derecho desplaza; Alt+izquierdo orbita; central desplaza. Los atajos espaciales requieren foco en el visor. Los controles no editan geometría.

Intro abre un proyecto reciente o un resultado de la búsqueda de crónica. En la búsqueda de recursos, Intro lleva a los resultados; Intro sobre un recurso seleccionado lo elige. Los campos de búsqueda tienen un botón para borrarlos y los filtros de recursos pueden restablecerse juntos.

Giro: 0° permite girar libremente; otro valor activa ajuste angular. Cada arrastre se deshace de una vez. En el selector de actores/objetos, las flechas giran la previsualización sin colocar nada. El menú contextual de un actor/objeto propio incluye + Conversación.
