# Troubleshooting

**Cannot find the game:** Settings → select Vampire.exe from a complete installation. Do not select a shortcut.

**Chronicle missing:** press Playtest, close earlier game sessions and choose Multiplayer → LAN → New Game. Find the name shown in the editor. Start the game through RCM so it loads the prepared playtest.

**Changes missing:** save and press F5. Errors are shown and prevent launching. Editing custom assets also invalidates the previous build.

**Viewport failure:** enable Start without 3D viewport in Settings and restart. Data editing remains available. Installation diagnosis checks state or rebuilds catalogues without changing original resources.

**Recover work:** open Saved versions. Automatic recovery can be accepted or left for later. Duplicate chronicle copies custom assets too.

**Get help:** Help → Create support bundle creates a local ZIP without original assets or complete private projects. Sharing is your choice; nothing is sent automatically.

Game saves do not migrate between different structural contracts. Start a new game after changing scenes, flags or sequences.
