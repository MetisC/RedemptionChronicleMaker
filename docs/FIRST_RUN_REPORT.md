# Informe de primer arranque

El probe recorre los widgets Qt empaquetados: preferencias nuevas → selector de Vampire.exe → validación → catálogos → copias de ejemplos → bienvenida → nueva aventura → entrada → NPC/dialogue/trigger/quest → guardar/reabrir → compilación real → despliegue sintético → tutorial/Showcase → enlaces/gráfico.

No escribe en la instalación real. La comprobación de root/ownership se hace en una instalación sintética dentro del workspace. La preferencia setup_complete se verifica al reabrir; esto no acredita una segunda máquina ni el menú LAN.

Evidencia de desarrollo: research/product_close/dev_probe2/workspace/build/product_probe.json. Los informes del executable final y rutas alternativas se conservan bajo research/product_close/portable/. Los tiempos son de este PC, no objetivos garantizados. El ensayo de desarrollo inicial tardó aproximadamente 12 segundos en preparar catálogos y 21 segundos en todo el circuito.
