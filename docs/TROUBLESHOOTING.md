# Resolver problemas

**No encuentro el juego:** Configuración → selecciona Vampire.exe de una instalación completa. No selecciones un acceso directo.

**No aparece la crónica:** pulsa Probar, cierra cualquier sesión anterior y entra en Multiplayer → LAN → New Game. Busca el nombre mostrado en el editor. La ventana del juego debe haberse abierto desde RCM para cargar la prueba preparada.

**Cambios sin aparecer:** guarda y pulsa F5. Si hay errores, el editor los muestra y no inicia el juego. Cambiar recursos propios también invalida la construcción anterior.

**El visor falla:** activa Iniciar sin visor 3D en Configuración y reinicia. La edición de datos sigue disponible. Diagnóstico de instalación permite revisar el estado o reconstruir catálogos; no modifica recursos originales.

**Recuperar trabajo:** abre Versiones guardadas. Si existe recuperación automática, puedes recuperarla o dejarla para después. Duplicar crónica copia también sus recursos propios.

**Pedir ayuda:** Ayuda → Crear paquete de soporte. Se crea un ZIP local sin assets originales ni proyectos privados completos. Tú decides si compartirlo. No se envía automáticamente.

Guardar/cargar del juego no migra estructuras de versiones diferentes. Empieza una partida nueva después de cambiar escenas, flags o secuencias.
