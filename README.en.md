# Redemption Chronicle Maker — 1.0.0-rc8

In this workspace, open **Redemption Chronicle Maker.lnk** from the root folder.

Create campaigns for **Vampire: The Masquerade — Redemption** with original scenarios, NPCs, conversations, quests and events. Geometry stays read-only.

1. Open **RedemptionChronicleMaker.exe**. Select **Vampire.exe** when requested.
2. Choose **Quick tutorial**, **Full showcase** or **New chronicle**. Projects live outside the application.
3. Edit through Properties and Assistant…; save and press **PLAYTEST IN REDEMPTION (F5)**.
4. In the game: **Multiplayer → LAN → New Game**, select your chronicle. RCM prepares and launches the playtest; you control the menus.

No terminal, manual configuration or original authoring tools required. Settings controls language, game installation, automatic recovery and project folder.

The tutorial story was accepted by the user. New first-run setup, direct launching and Showcase still need manual game acceptance. This is a release candidate, not final 1.0. Local one-player use; networking remains experimental.
