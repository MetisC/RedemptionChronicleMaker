# Redemption Chronicle Maker — 1.0.0-rc4

En este workspace, abre **Redemption Chronicle Maker.lnk** desde la raíz.

Crea campañas para **Vampire: The Masquerade — Redemption** con escenarios originales, NPC, conversaciones, misiones y eventos. La geometría permanece intacta.

1. Abre **RedemptionChronicleMaker.exe**. Selecciona **Vampire.exe** si se solicita.
2. Elige **Tutorial rápido**, **Showcase completo** o **Nueva crónica**. Tus proyectos se guardan fuera del programa.
3. Edita mediante Propiedades y Asistente…; guarda y pulsa **PROBAR EN REDEMPTION (F5)**.
4. Dentro del juego: **Multiplayer → LAN → New Game**, elige tu crónica. RCM prepara y lanza la prueba; tú controlas los menús.

No necesitas terminal, configuración manual ni herramientas originales de autoría. Configuración permite cambiar idioma, instalación, recuperación automática y carpeta de proyectos.

La historia del tutorial fue aceptada por el usuario. El nuevo primer arranque, lanzamiento directo y Showcase siguen pendientes de prueba manual en el juego. Esta es una candidata, no una 1.0 final. Uso local con un jugador; red experimental.

RC4 añade **Encuentros dinámicos…**: emboscadas, oleadas, continuo, refuerzos y jefes por fases. En Campaña o desde el menú contextual del suelo 3D, elige enemigos, cantidad, puntos y activación. Abre chronicles/dynamic_lab/project.yaml para probarlos; el Showcase ofrece otro laboratorio opcional. El tutorial rápido permanece intacto. [Guía de encuentros](docs/DYNAMIC_ENCOUNTERS.md).
