# Redemption Chronicle Maker 1.0.0-rc2

A Windows release candidate for creating local Redemption chronicles through the editor. Open the executable, choose Vampire.exe once, open a tutorial or create a chronicle, then press F5 to playtest.

The short tutorial retains its accepted story and runtime. The new full Showcase is a separate example; it is generated and compiled, with native visual acceptance still required. No original authoring tools or editable geometry.

First-run projects and preferences live outside the replaceable application folder. Original game files remain read-only; RCM manages only its own per-chronicle folders. Legacy shared test folders are preserved.

Final 1.0 remains gated by the user's manual setup/playtest/showcase/save-load checks. No independent clean-machine or network verification is claimed.
