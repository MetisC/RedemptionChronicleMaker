# Redemption Chronicle Maker 1.0.0-rc3

A smaller, clearer release candidate for local chronicle authoring. Open the executable, choose Vampire.exe, open Quick tutorial or Full showcase, and press F5 to playtest.

RC3 simplifies existing panels, guidance and terminology. It also ties cached catalogues to the game installation's content, brings imported projects through normal safe opening, and refuses newer project formats safely. English/Spanish is selected in Settings and applied after restarting.

The short tutorial retains its accepted source and runtime. Showcase has a human adventure guide followed by optional laboratories and a complete technical index. Its story and event logic have not been expanded.

Projects remain outside the replaceable application. Atomic saves, recovery, backups, locks, original-game protection and managed playtest are preserved. No original authoring tools or game assets are distributed.

MANUAL RUNTIME TEST REQUIRED. This is not final 1.0. Run the manual checklist before acceptance; independent machine, physical DPI, real GPU and networking are not certified by offline probes.
