# Llegada al refugio

Abre **Ayuda → Crónica de prueba: el refugio**. Guarda tu copia y pulsa F5. Empieza una partida nueva: esta crónica tiene su propio contrato de guardado.

1. Busca la salida del club con etiqueta **Refuge** y púlsala. Acercarse no basta. Se retira el objeto original compatible para dejar paso; no se anima una puerta fija.
2. Elena te recibe. Elige ver la llegada o saltarla. También puedes hablar directamente con ella si interrumpes el inicio.
3. Durante la escena, el guardia mira, gesticula y camina. La cámara usa un travelling creado por RCM; suena un ruido situado y termina con un fundido.
4. Al recuperar el control aparece una rata débil. Acaba con ella y vuelve a hablar con Elena.
5. Completa el encargo y viaja a la segunda escena. Comprueba que no se repite la recompensa.

En el editor, abre Campaña → Secuencias → **The keeper checks the refuge**. La lista temporal reúne acciones normales; el botón de travelling permite ver y editar sus puntos. El recurso está en Recursos propios → Recorridos de cámara propios. Las acciones al comenzar una línea se editan en Propiedades de esa línea.

Esta escena es una prueba de aceptación pendiente. Sus coordenadas se han contrastado con las superficies originales y sus archivos se generan y compilan; eso no certifica todavía el camino nativo, el encuadre, las luces, el audio ni las cargas.
