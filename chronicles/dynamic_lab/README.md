# Laboratorio de encuentros dinámicos

Habla con Anezka y elige probar las oleadas. Después acércate al barril: entrar en su zona inicia el combate. Hay dos oleadas, un jefe al 50%/25%, refuerzos y un generador continuo que puedes iniciar, detener, pausar o reanudar desde Anezka. Todos usan Rat, el primer enemigo débil; sólo la rata jefe del ejemplo tiene más vida.

Guarda a mitad de cada prueba y carga: comprueba que no duplica actores, umbrales ni recompensas. Para crear tu propio combate, usa + Encuentro dinámico… o el menú contextual del suelo en 3D.
